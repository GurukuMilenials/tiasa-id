# Design System - tiasa.id

## 1. Identitas Visual
* **Karakter Merek**: Solutif, Handal, Modern, Cepat.
* **Tipografi Utama**: Plus Jakarta Sans / Inter.

## 2. Palette Warna
* **Primary (Teal)**: `#0F766E` (Brand utama), `#0D9488` (Hover/Interactive), `#CCFBF1` (Soft Background)
* **Secondary (Amber)**: `#F59E0B` (Aksen & CTA sekunder)
* **Neutral Dark**: `#0F172A` (Teks utama, Heading)
* **Neutral Light**: `#F8FAFC` (Latar belakang utama), `#F1F5F9` (Latar belakang kartu/elemen)
* **Border & Line**: `#E2E8F0`
* **Status**:
  * Success: `#10B981`
  * Warning: `#F59E0B`
  * Error: `#EF4444`

## 3. Tipografi
* **Display 1**: 36px / Bold / Line-height 1.2
* **Heading 1**: 28px / SemiBold / Line-height 1.3
* **Heading 2**: 20px / SemiBold / Line-height 1.4
* **Body Normal**: 16px / Regular / Line-height 1.5
* **Caption**: 14px / Medium / Line-height 1.4

## 4. Elemen Komponen
* **Button Primary**: Latar belakang Teal (`#0F766E`), teks putih, sudut membulat `rounded-lg`, padding `py-2.5 px-5`, transisi hover `#0D9488`.
* **Card**: Latar belakang putih, garis tepi `#E2E8F0`, sudut membulat `rounded-xl`, bayangan `shadow-sm`.
* **Input Text**: Garis tepi `#CBD5E1`, sudut `rounded-lg`, efek fokus `focus:ring-2 focus:ring-teal-500`.
